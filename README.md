# MOCHI — Drop 01 (Studio Demo)

Interactive concept flagship for **MOCHI** lip jelly — Drop 01 (Six Moods).

## Highlights
- **Studio-Mastered Scroll Film**: 172 desktop (`1920×1080`) + 86 mobile (`720×1280`) scroll-scrubbed frames powered by Lenis + GSAP ScrollTrigger.
- **29-Frame 3D Campaign Gallery**: Three.js concave panoramic lens with true physical push-in 3D camera parallax, momentum drag, and full-screen lightbox.
- **Six Moods (`#/flavours`)**: Interactive jelly-physics squeezable tubes with cap pop-off and monumental editorial chapters.
- **Wallpapers (`#/wallpapers`)**: Six `1290×2796` downloadable studio lock-screen wallpapers.
- **Simulated Studio Bag (`#/bag`)**: Interactive 3D tube stage with `SOFT10` first-squeeze perk and studio reservation receipt (no payment processing).
- **Luxury Ambient Audio**: Self-hosted Yamaha C5 Salamander Concert Grand Piano engine with marble-hall convolution reverb.
